1. 编号对应：[n] 的 n 对应来源列表第 n 条，与来源编号一一对应；不得自行重排、合并或新增编号。
2. 逐句标注：每个事实性陈述（数据、日期、事件、结论、引述）所在句子必须带 [n]；同一句由多个来源支撑时可并列标注（如 [1][3]），取实际支撑该句的来源。意见性/推理性表述可不带 [n]，但不得伪装成事实句。
3. 禁止编造：不得引用来源列表中不存在的编号；不得虚构来源内容；来源中的数字、日期、名称、单位必须如实转述，不得改写；无法从来源得到支撑的陈述，要么不写，要么明确标注为推断。
4. 来源不足如实说明：现有来源不足以支撑某事实或结论时，明确写出「现有来源未覆盖/证据有限」，不得用引用标记掩盖不确定性；来源之间存在冲突时并列引用并注明分歧，不得擅自裁断。
5. 时效敏感信息（版本号/价格/统计数字）优先采用来源中时间最新的一条，并保持其原有时间表述。
